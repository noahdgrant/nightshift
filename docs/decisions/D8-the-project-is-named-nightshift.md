# D8: The project is named nightshift

## Decision

The project is named **nightshift**. Skills use the `ns-` prefix, the CLI is `ns` (crate `nightshift`), user config lives at `~/.config/nightshift/`, unit branches are `ns/<unit-id>`, and runtime artifacts go in `.ns/<unit-id>/`.

## Reason

Renamed from software-factory. Other projects named nightshift exist (e.g. marcus/nightshift); kept anyway.
