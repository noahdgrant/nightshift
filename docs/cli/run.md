# `ns run`

## `ns run [<unit-id>] [--issue <n>] [--from <phase>] [--gates stop|auto] [--base <ref>] [--cpus <n>] [--fresh] [--dry-run] [--factory <dir>]`

Implements `ns run` in [docs/factory/run.md](../factory/run.md): creates or reuses the unit's worktree, reads `.ns/<unit>/*.md`, picks the next phase from the state table, runs the phase's harness headless in the worktree with the rendered prompt on stdin, and repeats until the unit is done, merged, split, stuck, paused or out of budget. With only `--issue`, the unit id is `<n>-<slug of the issue title>` (read with `gh issue view`).

- **Harness.** Each phase uses the `command_write` of its harness: `[harness.<name>]` from the user config, else the built-in. The built-in claude command for `ns run` is `claude -p --permission-mode bypassPermissions --model {model} --output-format stream-json --verbose`. Headless `acceptEdits` can't run shell commands, and the phases need Bash. Permissions are bypassed, so the agent can run any command as your user; cwd is always the unit's worktree, but nothing else confines it. Run it on a machine where that is acceptable. A configured claude command gets `--output-format stream-json --verbose` added if it lacks them.
- **Files.** Transcripts: `<git-common-dir>/ns/transcripts/<unit>/<phase>-<attempt>.jsonl` (plus `.stderr`). Run log: `<git-common-dir>/ns/runs.jsonl`. Locks: `<git-common-dir>/ns-run-<unit>.lock` (one `ns run` per unit), `<git-common-dir>/ns-watch.lock` (one `ns watch` per repo), `<git-common-dir>/ns-merge.lock` (one merge step's update, CI wait and merge at a time per repo) and `<git-common-dir>/ns-worktree.lock` (one `ns worktree new` creating a worktree at a time per repo), each an OS `flock` whose file names the holder while held.
- **Guards.** After every phase: the default branch on `origin` must not have moved to a commit of this unit, and a PR named in `pr.md` must not be merged. Either stops the run as stuck.
- **Merge.** With `[merge] policy = "auto"`, a passing `pr.md` leads to the merge step: under `[gate] local = "build-only"`, update a PR head that lacks the default branch's tip and gate nothing locally; else with a gate and `local_queue` on (the default), gate the merge of the PR head with the default branch in a scratch worktree; else update a branch that is behind and gate the PR head. Outside the local queue a PR is updated only when the commits it lacks change one of its files; wait while main's CI is red before the merge lock; wait for checks to register on the PR head (bounded by `ci_register_timeout`), wait for CI (bounded by `ci_timeout_minutes`), send CI failures and conflicts back to build (conflicts to ship under `build-only`), leave PRs that change `human_review` files to a human, else `gh pr merge --squash`. Outcome `merged`.
- **Quality records.** When a unit ends `merged`, `done` or `stuck`, `ns run` pushes one record per review attempt to `origin`'s `nightshift/quality` branch. If the push fails, the records wait in `<git-common-dir>/ns/quality-outbox.jsonl` for the next run, and the unit's outcome is unchanged.
- **Cleanup.** After its merge step merges the PR and the unit's records are saved (pushed, or in the outbox), `ns run` removes the unit's worktree and local `ns/<unit>` branch. A worktree with uncommitted changes to tracked files, or a branch holding changes the merged PR head doesn't, stays. `cleanup` in the output says which, and why. A run that ends with the worktree kept (`done`, `stuck`, or `merged` and kept) deletes the paths in the worktree's `build-output` row of `docs/agents/stack.md` and logs `build_output_removed`.
- **Billing.** `[defaults] billing = "subscription"` (the default) removes `ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, `ANTHROPIC_BASE_URL` and `CLAUDE_CODE_USE_BEDROCK`/`_VERTEX`/`_FOUNDRY` from claude's environment and `OPENAI_API_KEY`, `OPENAI_BASE_URL` and `CODEX_API_KEY` from codex's, drops `--bare`, and refuses to start (exit 2) without `~/.claude/.credentials.json` or `CLAUDE_CODE_OAUTH_TOKEN`. A usage-limit error from claude ends the run as `paused` (exit 4) without using an attempt. `budget_usd` is a soft cap on the reported cost, unset by default on a subscription.
- **CPU share.** `--cpus <n>` sets `NS_CPUS`, `RUST_TEST_THREADS` and `CARGO_BUILD_JOBS` to `<n>` for every phase and gate, leaving any of them already set in the environment as it is. The `start` event in the run log records each value and whether it was `computed` or `inherited`. Without `--cpus` none is set. `ns watch` passes `--cpus max(1, cores / --parallel)`. `--cpus 0` or a non-number exits 2. Details in `docs/factory/watch.md` ("Parallel units").
- `--fresh` forgets the attempts and credits an unfinished run left in `.ns/<unit>/state.json`, for instance after fixing an artifact by hand. Without it, a run resumes them (see [Run](../factory/run.md)).
- `--dry-run` prints the next decision, the rendered prompt and the command. It creates no worktree, takes no lock, and calls no harness.
