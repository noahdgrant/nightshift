###   BREAKING CHANGES

* **cli:** ns guard-hooks no longer denies the forms it can't read literally: expansions, aliases, nested shells, cd into a protected directory, HUSKY=0, SKIP= and GIT_CONFIG_* variables, and git config writes of core.hooksPath. Its denials all start "ns: blocked:"; the "ns: denied:" rewrite request is gone.
* **cli:** a phase artifact's reason is its `reason` key, not the body's first line, and a moved base is `cause: base_moved`, not a first line starting `base moved`. ns reads artifacts with no `schema` key as ns-artifact/1 by the old rules.
